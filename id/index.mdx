## Ringkasan

Base URL: `https://orders.balaipedia.com/v1`. Semua request dan respons adalah JSON melalui HTTPS (HTTP biasa tidak tersedia). Kirim `Content-Type: application/json` pada request yang memiliki body. Timestamp menggunakan format ISO 8601 UTC. Jumlah dalam mata uang akun Anda (contoh dalam dokumentasi ini: `USD`). Hanya `GET` dan `POST` yang digunakan.

<Warning>
  API ini hanya untuk penggunaan **server-to-server**. Jangan pernah menaruh API key Anda di browser atau kode aplikasi mobile.
</Warning>

## Konvensi respons

- **Setiap respons dari API adalah JSON**, termasuk error, URL yang tidak dikenal, dan method HTTP yang salah. Respons membawa header `X-Request-Id` (nilai yang sama dengan `request_id` di body error). Satu-satunya halaman HTML adalah dokumentasi ini.
- **Kegagalan platform.** Dalam kasus langka, kegagalan dapat terjadi sebelum request Anda mencapai aplikasi kami (misalnya outage gateway atau jaringan). Respons `5xx` seperti itu mungkin bukan JSON. Selalu periksa status HTTP terlebih dahulu dan parse body hanya jika berupa JSON. Perlakukan setiap `5xx` atau timeout jaringan sebagai dapat dicoba ulang (lihat [Percobaan ulang](/id/errors#percobaan-ulang)).
- Respons sukses mengembalikan objek secara langsung (tanpa wrapper). Respons error selalu mengembalikan `{"error":{"code","message","request_id"}}` (lihat [Error](/id/errors)); cabang berdasarkan `code`, bukan `message`.
- Field yang didokumentasikan sebagai _nullable_ selalu ada dan bernilai `null` ketika belum ada nilai (misalnya `completed_at` pada order yang masih diproses). Field tidak pernah dihilangkan atau `undefined`.
- Respons hanya berisi informasi tentang order dan akun Anda sendiri. Tidak ada detail sistem internal atau pihak ketiga yang disertakan.
- CORS tidak diaktifkan: panggil API dari server Anda, bukan dari browser.
