---
title: "Quickstart"
description: "Dari API key ke order pertama Anda dalam empat langkah."
---

Jalankan perintah berikut dari server atau terminal Anda, dan ganti `YOUR_KEY` dengan key yang kami kirimkan melalui email (lihat [Autentikasi](/id/authentication)).

<Steps>
  <Step title="Periksa layanan">
    Tidak perlu key.

    ```bash
    curl https://orders.balaipedia.com/v1/ping
    ```

    Mengembalikan `{"ok":true,...}`.
  </Step>
  <Step title="Periksa key dan saldo Anda">
    ```bash
    curl https://orders.balaipedia.com/v1/balance \
      -H "Authorization: Bearer YOUR_KEY"
    ```

    `200` beserta saldo Anda berarti key berfungsi; `401` berarti key tidak ada atau salah.

    <CodeGroup>

    ```json USD
    {"object":"balance","balance":42.35,"currency":"USD","price_per_order":0.15}
    ```

    ```json IDR
    {"object":"balance","balance":0,"currency":"IDR","price_per_order":2500}
    ```

    </CodeGroup>
  </Step>
  <Step title="Buat order">
    <Warning>
      Ini order sungguhan: undangan sungguhan dikirim dan didebet sesuai harga Anda, jadi gunakan alamat email milik Anda sendiri selama pengujian.
    </Warning>

    ```bash
    curl -X POST https://orders.balaipedia.com/v1/orders \
      -H "Authorization: Bearer YOUR_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: 6f1c2f7e-9a4b-4d0e-8f3a-1b2c3d4e5f60" \
      -d '{"email":"your.name@gmail.com","reference":"TEST-1"}'
    ```

    Anda mendapat `201` dan order dengan `"status":"processing"`. Simpan `id`-nya. `201` berarti diterima, belum terkirim. Lihat [Buat order](/id/api-reference/create-order).
  </Step>
  <Step title="Dapatkan hasilnya">
    Biasanya dalam hitungan detik order menjadi `success`, atau `error` dengan `note` dan refund otomatis (order bisa melewati `pending` jika pengiriman tertunda sebentar). Daftarkan [webhook](/id/webhooks) (disarankan) dan tunggu event-nya, atau polling [`GET /orders/{id}`](/id/api-reference/get-order).

    ```bash
    curl https://orders.balaipedia.com/v1/orders/BP-7K3M9QXA \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </Step>
</Steps>

```text
POST /orders  →  201 processing  →  order.success   (invitation accepted by the recipient's mail server)
                                    or  order.error     (not delivered; charge refunded automatically)
```

Email yang langsung ditolak tidak pernah menjadi order: Anda langsung mendapat `422` dan tidak ada yang didebet. Lihat juga [Menguji integrasi Anda](/id/testing).
