Kirim hingga 10 order dalam satu request. Setiap email menjadi order tersendiri dengan Order ID sendiri (`BP-...`), didebet dan dilacak persis seperti [`POST /orders`](/id/api-reference/create-order), sama seperti mengirim beberapa email ke [Bot Telegram](/id/telegram-bot). Order diantrekan dan dikirim di latar belakang, sehingga respons kembali dengan cepat dan setiap order berstatus `processing`.

Header: `Authorization: Bearer YOUR_KEY` dan `Content-Type: application/json` (wajib), serta `Idempotency-Key` (opsional, disarankan).

## Header

<ParamField header="Idempotency-Key" type="string">
  Opsional, disarankan. 8-64 karakter, format sama dengan `POST /orders`. Key ini berlaku untuk seluruh request: ulangi request yang sama dengan key yang sama dan daftar email yang sama untuk mendapatkan hasil aslinya kembali (header `Idempotent-Replayed: true`) tanpa membuat atau mendebet apa pun lagi. Key yang sama dengan daftar email yang berbeda ditolak dengan `422 idempotency_conflict`.
</ParamField>

## Body

Pilih **salah satu** dari dua opsi berikut.

<ParamField body="orders" type="array">
  **Opsi 1 (disarankan).** Array berisi order: 1 sampai 10 objek dengan field yang sama seperti [`POST /orders`](/id/api-reference/create-order#body): `email` (wajib, tepat satu alamat), serta `name`, `lang`, `reference`, `allow_duplicate` yang opsional. JSON biasa, tanpa escape baris baru, dan Anda bisa mengatur `reference` per order.
</ParamField>

<ParamField body="emails" type="string">
  **Opsi 2 (jalan pintas).** Satu string berisi satu email per baris. Pemisahnya hanya baris baru: tulis `\n` atau `\r\n` di dalam string JSON (tekanan tombol Enter tidak bisa muncul langsung di dalam string JSON, harus ditulis sebagai escape `\n` / `\r\n`; setiap library JSON melakukannya otomatis jika teks Anda berisi baris baru). Spasi, koma, dan titik koma bukan pemisah. Baris kosong diabaikan. `lang` dan `allow_duplicate` opsional di tingkat atas (dua field berikutnya) berlaku untuk setiap email.
</ParamField>

<ParamField body="lang" default="en" type='"en" | "id"'>
  Hanya untuk Opsi 2 (di Opsi 1, atur `lang` di dalam setiap order). Bahasa email yang dikirim ke pembeli: Inggris atau Indonesia. Opsional, default `"en"`. Berlaku untuk setiap email dalam request. Nilai lain membuat setiap item gagal dengan `invalid_request`. Ini tidak bergantung pada mata uang akun Anda.
</ParamField>

<ParamField body="allow_duplicate" default="false" type="boolean">
  Hanya untuk Opsi 2 (di Opsi 1, atur di dalam setiap order). Opsional, default `false`. Secara default, email yang baru saja menerima undangan ditolak sebagai `duplicate_order`; atur `true` untuk mengirim lagi (didebet), hanya jika undangan sebelumnya adalah salah satu order Anda sendiri. Nilainya harus `true` atau `false`, jika tidak seluruh request ditolak dengan `400 invalid_request`.
</ParamField>

Kirim `emails` atau `orders`, jangan keduanya (`400 invalid_request`). Lebih dari 10 email atau order ditolak dengan `400 too_many_orders`.

## Format email

Tulis setiap email sebagai satu alamat lengkap tanpa spasi, koma, atau titik koma, misalnya `buyer@gmail.com` (spasi sebelum atau sesudah alamat diabaikan dan huruf diubah menjadi huruf kecil). Alamat dengan spasi di dalamnya, koma, atau lebih dari satu alamat dalam satu baris, misalnya `buyer @ gmail .com` atau `a@gmail.com,b@gmail.com`, langsung ditolak sebelum ada yang didebet, sebagai `email_rejected` untuk item tersebut dengan `reason: "invalid_format"`. Email lain dalam request yang sama tetap diproses. Jika satu baris berisi dua alamat, letakkan masing-masing di barisnya sendiri.

## Respons `200 OK`

Request itu sendiri berhasil setiap kali Anda mendapat `200`; periksa setiap item di `results`. Item diproses secara terpisah: satu email yang ditolak tidak pernah menghalangi yang lain, dan Anda hanya didebet untuk item dengan `status: "created"`. Hasil mengikuti urutan input Anda, baris demi baris atau item demi item (`index` adalah posisinya, dimulai dari 0).

`balance` adalah saldo Anda setelah seluruh request. Setiap order yang dibuat kemudian berperilaku seperti order dari `POST /orders`: poll [`GET /orders/{id}`](/id/api-reference/get-order) atau gunakan [webhook](/id/webhooks) Anda, dan pengiriman yang gagal di-refund otomatis.

## Error per item

Item dengan `status: "error"` membawa nilai `code` error yang sama seperti `POST /orders` (tanpa `request_id`; gunakan yang ada di header `X-Request-Id`). Item tersebut tidak didebet.

| code | Arti |
| --- | --- |
| `invalid_request` | Item tidak valid: `email` tidak ada, `lang` salah, atau field dengan tipe yang salah. |
| `duplicate_order` | Email sudah menerima undangan baru-baru ini (lihat `allow_duplicate`), sedang diproses, atau muncul lebih dari sekali dalam request ini (hanya kemunculan pertama yang dipakai). |
| `email_rejected` | Alamat gagal validasi. Lihat `reason`, `note`, dan `suggestion`. Alamat dengan format salah (spasi, koma, beberapa alamat dalam satu baris) langsung ditolak dengan `reason: "invalid_format"`. |
| `insufficient_credit` | Saldo Anda habis di tengah proses. Item didebet berurutan, sehingga item awal mungkin sudah dibuat dan item berikutnya gagal. Mencakup `balance`, `required`, `currency`. |
| `out_of_capacity`, `temporarily_unavailable` | Kami tidak dapat menerima order saat ini. Tidak didebet. Coba lagi nanti (gunakan `Idempotency-Key` yang sama hanya jika semua item gagal; jika tidak, kirim hanya email yang gagal dalam request baru). |

## Error untuk seluruh request

| HTTP | code | Arti |
| --- | --- | --- |
| 400 | `invalid_json`, `invalid_request`, `too_many_orders` | Body bukan JSON yang valid atau bukan objek, `emails` maupun `orders` tidak dikirim (atau keduanya dikirim), isinya kosong atau tipenya salah, header tidak valid, atau ada lebih dari 10 item (`too_many_orders`, mencakup `max`). |
| 409 | `request_in_progress` | Request dengan `Idempotency-Key` ini masih diproses. Tunggu sebentar lalu kirim request yang sama lagi. |
| 422 | `idempotency_conflict` | `Idempotency-Key` ini sudah dipakai dengan daftar email yang berbeda. |
| 429 | `rate_limited` | Request massal dihitung sebagai satu request per email terhadap batas per menit Anda (sama seperti bot Telegram). Tunggu selama `Retry-After` detik. |
| 401 / 403 / 5xx | - | Sama seperti endpoint lainnya (lihat [Error dan batasan](/id/errors)). |

## Mencoba ulang dengan aman

- Selalu kirim `Idempotency-Key`. Jika koneksi terputus, kirim request yang sama lagi dengan key yang sama: Anda mendapat hasil aslinya dan tidak pernah didebet dua kali.
- Tanpa key, periksa `GET /orders?reference=...` sebelum mencoba ulang, karena email yang sudah dipesan akan ditolak sebagai `duplicate_order`.
- Untuk mencoba ulang hanya item yang gagal, kirim request baru (key baru) yang hanya berisi email tersebut.

```bash curl (Opsi 1)
curl -X POST https://orders.balaipedia.com/v1/orders/bulk \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 5c1e7a90-2b64-4f1d-8a37-0d9e6b4c2f81" \
  -d '{"orders":[
    {"email":"buyer1@gmail.com","reference":"ORD-1"},
    {"email":"buyer2@gmail.com","reference":"ORD-2","lang":"id","name":"Budi"}
  ]}'
```

```javascript Node.js (Opsi 1)
const res = await fetch("https://orders.balaipedia.com/v1/orders/bulk", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.BP_API_KEY,
    "Content-Type": "application/json",
    "Idempotency-Key": key   // e.g. a UUID you stored with this batch
  },
  body: JSON.stringify({ orders: [
    { email: "buyer1@gmail.com", reference: "ORD-1" },
    { email: "buyer2@gmail.com", reference: "ORD-2", lang: "id", name: "Budi" }
  ] })
});
const data = await res.json();   // 200 = request processed: check every item in data.results
```

```python Python (Opsi 1)
r = requests.post("https://orders.balaipedia.com/v1/orders/bulk",
    headers={"Authorization": "Bearer " + os.environ["BP_API_KEY"], "Idempotency-Key": key},
    json={"orders": [
        {"email": "buyer1@gmail.com", "reference": "ORD-1"},
        {"email": "buyer2@gmail.com", "reference": "ORD-2", "lang": "id", "name": "Budi"},
    ]})
data = r.json()   # 200 = request processed: check every item in data["results"]
```
