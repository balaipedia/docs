api: "GET https://orders.balaipedia.com/v1/transactions"
---

Top-up, biaya, pengembalian dana, dan penyesuaian, yang terbaru pertama. Saldo kredit dan transaksi Anda tidak terpengaruh oleh pembersihan data order.

## Parameter query

<ParamField query="limit" default="20" type="integer">
  1-100, default 20.
</ParamField>

<ParamField query="cursor" type="integer">
  Lewatkan `next_cursor` dari halaman sebelumnya. Cursor yang tidak valid mengembalikan `400`.
</ParamField>

## Respons

`type` adalah salah satu dari `topup`, `charge`, `refund`, `adjustment`. Biaya adalah angka negatif. `order_id` diisi untuk biaya dan pengembalian dana; top-up membawa `topup_id` sebagai gantinya.

<RequestExample>

```bash curl
curl "https://orders.balaipedia.com/v1/transactions?limit=20" \
  -H "Authorization: Bearer YOUR_KEY"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{"object":"list","has_more":false,"next_cursor":null,"data":[
  {"id":581,"type":"charge","amount":-0.15,"balance_after":42.2,"currency":"USD","order_id":"BP-7K3M9QXA","created_at":"2026-11-12T03:10:00.000Z"}
]}
```

</ResponseExample>
