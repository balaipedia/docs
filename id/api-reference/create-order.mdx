---
title: "Buat order"
description: "Buat order dan kirim undangan."
api: "POST https://orders.balaipedia.com/v1/orders"
---

Mengirim satu undangan tim Canva Pro ke satu email pembeli. Order didebet sesuai harga Anda saat diterima.

## Header

Wajib: `Authorization: Bearer YOUR_KEY` dan `Content-Type: application/json`.

<ParamField header="Idempotency-Key" type="string">
  Opsional, disarankan. 8-64 karakter (huruf, angka, `_ . : -`), misalnya UUID. Simpan bersama order Anda agar percobaan ulang memakai key yang sama.

  - **Kenapa:** saat request timeout atau koneksi terputus, Anda tidak tahu apakah order sudah dibuat. Ulangi request dengan key dan email yang sama: Anda mendapat order yang sama kembali (header `Idempotent-Replayed: true`) dan tidak pernah didebet dua kali.
  - Key diingat selama 24 jam.
  - Memakai ulang key dengan email berbeda mengembalikan `422 idempotency_conflict`.
</ParamField>

<Warning>
  Tanpa key, request tetap berfungsi dan pemeriksaan duplikat email (`409 duplicate_order`) tetap berlaku, tetapi kami tidak bisa mengenali percobaan ulang sebagai request yang sama. Mencoba ulang request yang timeout dengan `allow_duplicate: true` tanpa key dapat membuat dan mendebet order kedua.
</Warning>

## Body

<ParamField body="email" type="string" required>
  Email pembeli. Satu alamat per order, misalnya `buyer.name@gmail.com`.

  - Tulis alamat lengkap tanpa spasi, koma, atau titik koma. Spasi sebelum atau sesudahnya diabaikan dan huruf diubah menjadi huruf kecil.
  - Alamat dengan spasi atau koma di dalamnya, seperti `buyer @ gmail .com`, langsung ditolak dengan `422 email_rejected` (`reason: "invalid_format"`).
  - Dua alamat menghasilkan `400 invalid_request`. Untuk memesan bagi beberapa pembeli sekaligus (hingga 10), gunakan [`POST /orders/bulk`](/id/api-reference/create-orders-bulk).
</ParamField>

<ParamField body="name" type="string">
  Opsional. Digunakan dalam sapaan (maks 60 karakter).
</ParamField>

<ParamField body="lang" default="en" type="string">
  `"en"` | `"id"`. Bahasa email yang dikirim ke pembeli: Inggris atau Indonesia. Default `"en"`. Nilai lainnya ditolak dengan `400`. Ini tidak bergantung pada mata uang akun Anda.
</ParamField>

<ParamField body="reference" type="string">
  Referensi order Anda sendiri (maks 64). Dikembalikan dalam respons dan webhook; dapat dicari melalui endpoint daftar.
</ParamField>

<ParamField body="allow_duplicate" type="boolean">
  `true` atau `false` saja. Secara default, email yang telah menerima undangan dalam 30 hari terakhir ditolak dengan `409`. Atur true untuk mengirim ulang (dikenakan biaya). Pengiriman ulang hanya diizinkan jika undangan sebelumnya merupakan order milik Anda sendiri; jika tidak, tetap ditolak dengan `409`.
</ParamField>

## Respons

Mengembalikan [objek order](/id/api-reference/get-order#objek-order) dengan status `201 Created`, ditambah `balance`: saldo Anda setelah pengurangan biaya.

## Cara order diproses

`201` berarti order **diterima dan didebet**, belum terkirim. Order selalu dimulai sebagai `processing` dan responsnya seketika. Pantau hasilnya dengan [webhook](/id/webhooks) (direkomendasikan) atau [`GET /orders/{id}`](/id/api-reference/get-order).

```text
processing  →  success                 (normal, usually within seconds)
processing  →  pending  →  success    (delivery was briefly delayed, we keep retrying)
processing  →  error                   (could not be delivered, charge refunded automatically)
```

Anggap `processing` dan `pending` sebagai "sedang berjalan" dan bertindaklah hanya pada `success` atau `error`. Jika order berakhir sebagai `error`, `note` menjelaskan alasannya dan email yang sama dapat dikirim lagi sebagai order baru.

## Ditolak oleh validasi, `422` (tidak ada biaya)

`422` berarti email langsung ditolak dan tidak ada yang didebet (lihat contoh `422 Rejected`). Beberapa masalah baru ditemukan setelah order diterima; order tersebut berakhir sebagai `error` dengan `note` dan refund. Tangani keduanya.

- `reason`: kode stabil untuk percabangan (tabel di bawah).
- `note`: penjelasan singkat yang bisa Anda catat atau tampilkan.

| reason | Arti |
| --- | --- |
| `invalid_format` | Bukan format email yang valid. |
| `typo_domain` | Kemungkinan typo pada domain; `suggestion` mungkin berisi alamat yang diperbaiki. |
| `domain_no_mail` | Domain tidak ada atau tidak menerima email. |
| `mailbox_not_found` | Mailbox tidak ada. |
| `mailbox_full` | Kotak masuk penerima penuh. Ini bukan blokir permanen: minta penerima mengosongkan ruang, lalu coba lagi order yang sama setelah 30 menit. |
| `disposable_email` | Layanan email sementara / sekali pakai. |
| `address_undeliverable` | Alamat ini sebelumnya gagal atau berada dalam daftar blokir kami. |
| `high_risk` | Ditandai sebagai berisiko (spam trap, penyalahgunaan, do-not-mail). |
| `invalid_email` | Kegagalan validasi lainnya. |

## Respons kegagalan lainnya

Setiap kegagalan menggunakan body yang sama, `{"error":{"code","message","request_id"}}`. Lakukan percabangan berdasarkan `code`, bukan `message`. Request yang gagal tidak pernah membuat order. Kredit hanya dikenakan pada `201`.

| HTTP | code | Tindakan |
| --- | --- | --- |
| 400 | `invalid_request` | Perbaiki request, jangan coba ulang tanpa perubahan. Satu email per request: tidak ada bulk, tidak ada daftar, dan tidak ada alamat yang dipisahkan koma, titik koma, atau spasi. |
| 400 | `invalid_json` | Kirim JSON yang valid dengan `Content-Type: application/json`. |
| 401 | `unauthorized` | Periksa header `Authorization: Bearer ...` dan key-nya. |
| 402 | `insufficient_credit` | Isi ulang saldo, lalu kirim request lagi. Tidak ada yang dikenakan biaya. |
| 409 | `duplicate_order` | Email yang sama baru-baru ini dipesan. Kirim `"allow_duplicate": true` hanya jika Anda benar-benar ingin mengirim (dan dikenakan biaya) lagi. Beberapa duplikat tidak dapat dikirim ulang sama sekali dan memerlukan bantuan support. |
| 409 | `request_in_progress` | Tunggu beberapa detik dan kirim request yang sama dengan key yang sama lagi. |
| 422 | `email_rejected` | Tidak dikenakan biaya. Minta pembeli untuk memberikan alamat yang benar. |
| 422 | `idempotency_conflict` | Gunakan key baru untuk email yang berbeda. |
| 429 | `rate_limited` | Tunggu selama jumlah detik di header `Retry-After`, lalu coba ulang. |
| 503 | `temporarily_unavailable` | Tidak dikenakan biaya. Header `Retry-After: 30`. Coba ulang setelah itu, dengan `Idempotency-Key` yang sama jika Anda mengirimkannya. |
| 503 | `out_of_capacity` | Tidak dikenakan biaya, tidak ada order yang dibuat. Header `Retry-After: 300`: tunggu minimal selama itu, lalu coba ulang dengan `Idempotency-Key` yang sama jika Anda mengirimkannya. Jangan coba ulang beruntun tanpa jeda. |

<Accordion title="Contoh body error">
  ```json 400 invalid_request
  {"error":{"code":"invalid_request","message":"Only one email address per order.","request_id":"req_..."}}
  ```

  Pesan `invalid_request` lainnya: `"email" is required.`, `"email" must be a string.`, `"lang" must be "id" or "en".`, `"allow_duplicate" must be a boolean.`, `Request body must be a JSON object.`, `Idempotency-Key must be 8-64 chars (letters, digits, _ . : -).`

  ```json 400 invalid_json
  {"error":{"code":"invalid_json","message":"Request body must be valid JSON.","request_id":"req_..."}}
  ```

  ```json 401 unauthorized
  {"error":{"code":"unauthorized","message":"Missing or invalid API key.","request_id":"req_..."}}
  ```

  ```json 402 insufficient_credit
  {"error":{"code":"insufficient_credit","message":"Your credit balance is too low for this order.","balance":0,"required":0.15,"currency":"USD","request_id":"req_..."}}
  ```

  ```json 409 duplicate_order
  {"error":{"code":"duplicate_order","message":"This email already received an invitation recently. Set \"allow_duplicate\": true to send again (charged).","request_id":"req_..."}}
  ```

  ```json 409 request_in_progress
  {"error":{"code":"request_in_progress","message":"A request with this Idempotency-Key is still being processed.","request_id":"req_..."}}
  ```

  ```json 422 idempotency_conflict
  {"error":{"code":"idempotency_conflict","message":"This Idempotency-Key was already used with a different email.","request_id":"req_..."}}
  ```

  ```json 429 rate_limited
  {"error":{"code":"rate_limited","message":"Too many requests. Slow down.","request_id":"req_..."}}
  ```

  ```json 503 temporarily_unavailable
  {"error":{"code":"temporarily_unavailable","message":"We could not process this order right now. No credit was charged. Please retry shortly.","request_id":"req_..."}}
  ```

  ```json 503 out_of_capacity
  {"error":{"code":"out_of_capacity","message":"We are temporarily out of capacity for new orders. No credit was charged. Please retry later.","request_id":"req_..."}}
  ```
</Accordion>

<Note>
  **Tentang `out_of_capacity`:** kami belum dapat memenuhi order baru saat ini. Error ini juga bisa diterima oleh salah satu dari beberapa order yang dikirim bersamaan, ketika kapasitas terakhir baru saja diambil order lain (dari API atau bot Telegram). Setiap order diputuskan sendiri-sendiri, jadi request yang menerima error ini hanya tidak kebagian tempat.
</Note>

Status lainnya (`403`, `404`, `405`, `413`, `500`) tercantum di bawah [Errors](/id/errors).

```javascript Node.js
// Node 18+
const key = require("crypto").randomUUID();   // store it with your order so a retry reuses it
const res = await fetch("https://orders.balaipedia.com/v1/orders", {

    "Authorization": "Bearer " + process.env.BP_API_KEY,
    "Content-Type": "application/json",

try { data = JSON.parse(text); } catch (e) {}   // a 5xx from the platform may not be JSON

```
