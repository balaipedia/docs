---
title: "Dapatkan status order"
description: "Dapatkan status dari satu order."
api: "GET https://orders.balaipedia.com/v1/orders/{id}"
---

Mengembalikan satu order yang dibuat dalam 60 hari terakhir (lihat [Data retention](/id/data-retention)). Lakukan polling secara hemat; lebih disukai menggunakan [webhook](/id/webhooks). ID order yang tidak dikenal, atau order yang lebih lama dari 60 hari, mengembalikan `404 not_found`.

## Parameter path

<ParamField path="id" type="string" required>
  ID order yang dikembalikan oleh `POST /orders`, misalnya `BP-7K3M9QXA`.
</ParamField>

## Objek order

<ResponseField name="id" type="string">
  ID order, misalnya `BP-7K3M9QXA`.
</ResponseField>

<ResponseField name="object" type="string">
  Selalu `"order"`.
</ResponseField>

<ResponseField name="email" type="string">
  Email pembeli (dinormalisasi menjadi huruf kecil).
</ResponseField>

<ResponseField name="reference" type="string | null">
  Referensi Anda, atau `null` jika Anda tidak mengirimkannya.
</ResponseField>

<ResponseField name="status" type="string">
  Lihat [Status order](#status-order).
</ResponseField>

<ResponseField name="note" type="string | null">
  Hanya saat `status` adalah `error`: penjelasan singkat yang dapat dibaca manusia mengapa order gagal (misalnya kotak masuk penerima penuh). `null` untuk status lainnya. Penyusunan kata dapat disempurnakan dari waktu ke waktu, jadi jangan parsing: lakukan percabangan berdasarkan `status`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 UTC.
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  Saat status final saat ini ditetapkan; `null` saat belum final.
</ResponseField>

<ResponseField name="expires_at" type="string | null">
  Tanggal akhir langganan (`YYYY-MM-DD`) setelah diketahui.
</ResponseField>

<ResponseField name="amount" type="number">
  Harga yang dikenakan untuk order ini, dalam `currency`.
</ResponseField>

<ResponseField name="currency" type="string">
  `USD` atau `IDR`.
</ResponseField>

<ResponseField name="refunded" type="boolean">
  Apakah biaya telah dikembalikan. Order `error` dapat di-refund secara otomatis; admin juga dapat me-refund order secara manual. Refund manual mengatur field ini menjadi `true` dan, jika order berstatus `success`, mengubah statusnya menjadi `error`.
</ResponseField>

<ResponseField name="balance" type="number">
  Hanya dalam respons `201` dari `POST /orders`: saldo Anda setelah pengurangan biaya.
</ResponseField>

## Status order

| status | Arti | Final? |
| --- | --- | --- |
| `pending` | Pengiriman tertunda sementara dan kami terus mencoba ulang. Berakhir sebagai `success`, atau `error` jika masih belum terkirim setelah 72 jam. | Tidak |
| `processing` | Diterima dan didebet. Sedang dikirim (biasanya beberapa detik). Setiap order baru dimulai di sini. | Tidak |
| `success` | Email undangan diterima oleh server email penerima. (Ini tidak berarti pembeli sudah bergabung.) | Ya |
| `error` | Undangan tidak dapat dikirim, atau admin me-refund order secara manual. Kami menangani penyebabnya di sisi kami; periksa `refunded` untuk melihat apakah biaya telah dikembalikan. | Ya |

`success` dan `error` adalah **final**. Status pengiriman tidak berubah setelah order mencapai salah satunya. Satu-satunya pengecualian adalah refund manual oleh admin: order yang `success` dapat di-refund, yang mengubahnya menjadi `error` dengan `refunded: true` dan mengirim event `order.error` setelahnya.

Hanya ada empat status ini. Setiap kegagalan dilaporkan sebagai `error`, dan `note` memberi tahu Anda alasannya, sehingga order tidak pernah gagal tanpa penjelasan:

```json
{"id":"BP-7K3M9QXA","object":"order","status":"error","note":"The recipient's mailbox is full.","refunded":true, ...}
```

Kemungkinan catatan untuk order `error`: kotak masuk penerima penuh atau tidak ada; domain email tidak dapat menerima email; server email penerima menolak email; penerima melaporkan email sebagai spam; email tidak dapat dikirim dalam waktu 72 jam; email ini sudah menerima undangan baru-baru ini; kami tidak dapat mengirim order saat ini (kredit dikembalikan, silakan coba lagi sebentar lagi); order di-refund secara manual oleh admin; atau kegagalan pengiriman umum.
