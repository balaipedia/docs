Besides the API you can order and check your account from our Telegram bot. It is optional and separate from the API: the bot does **not** use `/v1` and never needs your API key. Orders from the bot use the same balance, price, validation and duplicate rules as the API, and appear in the same order list and transactions (marked as coming from the bot).

## Connect

<Steps>
  <Step title="Send your bot code">
    Open the bot link we send you, or open the bot and send the one-time bot code (`bpt_...`) that we emailed you. The code works once and expires 24 hours after it is created.
  </Step>
  <Step title="Check your account">
    The bot greets you by name and shows your balance, price per order and remaining quota.
  </Step>
  <Step title="Lost the code?">
    Ask support for a new one. To switch account send `/keluar` (or `/logout`) first.
  </Step>
</Steps>

<Warning>
  **Never send your API key (`bpk_...`) to the bot.** If you do, the bot deletes your message and warns you; ask support for a new key if it may have been seen by others.
</Warning>

## Ordering

- Send buyer emails in the chat, **one per line, up to 5 per message**. Write each as a complete address with no spaces or commas, for example `buyer@gmail.com`. Each email is validated and charged separately, exactly like one API order. More than 5 is refused. A line with a space or comma inside the address is rejected as `Invalid email format` and nothing is charged for it; a line without an `@` is ignored.
- Optional buyer name: add a line `nama: Budi` (or `name: Budi`) when sending a single email.
- Send an Order ID (for example `BP-7K3M9QXA`) to see that order's status. Only your own orders are found.
- If an email was ordered recently, the bot says so and offers **Send again** (charged) or **Cancel**. Pressing a button twice never creates two orders.
- If your balance is too low the order is not created and the bot shows a button to contact the admin for a top-up.
- Bot requests count toward the same rate limit as API requests.

## Commands and buttons

| Command | Button | What it does |
| --- | --- | --- |
| `/menu` (also `/start`, `/help`) | Menu | Main menu with your balance and quota. |
| `/riwayat` (`/history`) | Riwayat / History | Your recent orders and their status. |
| `/saldo` (`/balance`) | Saldo / Balance | Balance and latest transactions. |
| `/bahasa` (`/language`) | Bahasa / Language | Choose the bot language and the language of the email sent to buyers. |
| `/profil` (`/profile`) | Profil / Profile | Show or change your [email profile](/api-reference/set-profile) with buttons: **Change name**, **Change contact** (WhatsApp, Telegram or no contact), **Back to default**. After you tap one, send the value as a normal message. The default is the sender name Order Digital and no contact. Same rules and same setting as `POST /profile`. The typed forms still work too: `/profil nama Toko Maju`, `/profil wa 0812-3456-7890`, `/profil telegram tokomaju`, `/profil hapus`. |
| `/batal` (`/cancel`) |  | Cancel the current action. |
| `/keluar` (`/logout`) |  | Sign out and remove the keyboard. |

The button keyboard stays visible and you can hide or show it with the keyboard icon next to the message box. Any other `/command` is answered with "Unknown command" followed by the menu. A message that is not a command and contains no valid email is answered with "No email detected. Send buyer emails, one per line, each a complete address with no spaces or commas." followed by an example.

Bot messages follow your bot-language setting (Indonesian or English). It is separate from the language of the email your buyer receives.
