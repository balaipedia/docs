---
title: "List orders"
description: "List and filter your orders."
api: "GET https://orders.balaipedia.com/v1/orders"
---

Newest first. Only orders from the last 60 days are returned.

## Query parameters

<ParamField query="limit" type="integer" default="20">
  1-100, default 20. Values above 100 are clamped to 100.
</ParamField>

<ParamField query="cursor" type="integer">
  Pass the `next_cursor` of the previous page. An invalid cursor returns `400`.
</ParamField>

<ParamField query="status" type="string">
  One of `pending`, `processing`, `success`, `error`. An unknown value returns `400`.
</ParamField>

<ParamField query="reference" type="string">
  Only orders with exactly this reference.
</ParamField>

<ParamField query="email" type="string">
  Only orders for this buyer email.
</ParamField>

## Pagination

Pass `next_cursor` as `cursor` to get the next page. `next_cursor` is `null` when `has_more` is false. When nothing matches you get `{"object":"list","data":[],"has_more":false,"next_cursor":null}`.

<RequestExample>

```bash curl
curl "https://orders.balaipedia.com/v1/orders?status=error&limit=50" \
  -H "Authorization: Bearer YOUR_KEY"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{"object":"list","data":[ ...orders... ],"has_more":true,"next_cursor":1234}
```

</ResponseExample>
