---
title: "Quickstart"
description: "Check your balance, create your first order and track its status."
---

<Steps>
  <Step title="Get your API key">
    We email your key (`bpk_xxxxxxxx_...`) to you when your account is created. Store it in server-side secret storage. See [Authentication](/authentication).
  </Step>
  <Step title="Check your balance">
    ```bash
    curl https://orders.balaipedia.com/v1/balance \
      -H "Authorization: Bearer YOUR_KEY"
    ```

    <CodeGroup>

    ```json USD
    {"object":"balance","balance":42.35,"currency":"USD","price_per_order":0.15}
    ```

    ```json IDR
    {"object":"balance","balance":0,"currency":"IDR","price_per_order":2500}
    ```

    </CodeGroup>
  </Step>
  <Step title="Create an order">
    We recommend sending an `Idempotency-Key` header (optional; 8-64 characters, e.g. a UUID) so a retry never creates the same order twice.

    ```bash
    curl -X POST https://orders.balaipedia.com/v1/orders \
      -H "Authorization: Bearer YOUR_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: 6f1c2f7e-9a4b-4d0e-8f3a-1b2c3d4e5f60" \
      -d '{"email":"buyer@gmail.com","name":"Budi","lang":"en","reference":"ORD-10293"}'
    ```

    Save the returned `id` (e.g. `BP-7K3M9QXA`) with your own order. See [Create order](/api-reference/create-order).
  </Step>
  <Step title="Track the status">
    Register a [webhook](/webhooks) to receive status changes, or poll [Get order status](/api-reference/get-order) as a fallback.

    ```bash
    curl https://orders.balaipedia.com/v1/orders/BP-7K3M9QXA \
      -H "Authorization: Bearer YOUR_KEY"
    ```
  </Step>
</Steps>
